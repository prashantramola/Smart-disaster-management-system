Smart Disaster Management System

A disaster monitoring system developed during my Polytechnic using Arduino, sensors, and a web-based interface to display real-time sensor readings.

📌 About the Project

The Smart Disaster Management System was developed as a team project during my Polytechnic.

The system uses Arduino and multiple sensors to collect environmental readings. A web-based interface was also developed to display and monitor the collected data.

The main aim of the project was to explore how hardware, sensors, and web technologies can be combined to create a disaster monitoring solution.

🛠️ Technologies Used

- Arduino
- Sensors
- C/C++
- HTML
- CSS
- JavaScript

 👥 Team
